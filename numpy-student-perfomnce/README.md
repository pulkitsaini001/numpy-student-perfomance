# NumPy Student Performance Analytics

A NumPy-only student performance analytics project built from scratch using Python and NumPy.

## Features

- Generate student marks dataset
- Handle missing values
- Calculate total marks and percentage
- Subject-wise average analysis
- Find strongest and weakest subjects
- Find top-performing students
- Pass/Fail analysis
- Grade calculation
- Subject-wise pass percentage
- Search individual student reports
- Generate class performance dashboard
- Save cleaned dataset using NumPy

## Technologies Used

- Python
- NumPy

## Project Purpose

This project demonstrates how NumPy can be used for real-world data analysis without using Pandas, Matplotlib, or Scikit-learn.

## How to Run

```bash
pip install numpy
python main.py
